# 🎯 Pedro HR - Personal Portfolio

Uma landing page moderna e responsiva que apresenta meus projetos, habilidades e evolução como desenvolvedor fullstack. Construída com **React + Vite** para máximo desempenho e experiência do usuário.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![React](https://img.shields.io/badge/React-19.2-61dafb.svg)
![Vite](https://img.shields.io/badge/Vite-8.0-646cff.svg)

## ✨ Destaques

- 🎨 **Design Moderno & Responsivo** - Funciona perfeitamente em desktop, tablet e mobile
- ⚡ **Performance Otimizada** - Construído com Vite para HMR instantâneo e builds ultra-rápidos
- 🎯 **UX Intuitiva** - Navegação fluida e seções bem organizadas
- 💡 **Componentes Reutilizáveis** - Arquitetura limpa e escalável
- 🌙 **Acessibilidade** - Semântica HTML adequada e suporte a temas
- 📱 **Mobile-First** - Desenvolvido pensando em dispositivos móveis

## 📋 Seções do Portfolio

- **Hero** - Apresentação inicial com call-to-action

## 🛠️ Instalação & Setup

### Pré-requisitos
- Node.js 18+
- npm ou yarn

### Passos

1. **Clone o repositório**
```bash
git clone https://github.com/pedrohrdev/portfolio.git
cd portfolio
```

2. **Instale as dependências**
```bash
npm install
```

3. **Inicie o servidor de desenvolvimento**
```bash
npm run dev
```

A aplicação estará disponível em `http://localhost:5173`

## 📦 Scripts Disponíveis

```bash
# Desenvolvimento com HMR
npm run dev

# Build para produção
npm run build

# Preview do build
npm run preview

# Lint com ESLint
npm lint
```
